# Security Policy

## Supported versions

Only the latest `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.

Report privately through GitHub Security Advisories:

1. Open the repository on GitHub.
2. Go to **Security → Advisories → Report a vulnerability**.
3. Include: affected version/commit, reproduction steps, impact, and any proof of concept.

If private advisories are unavailable, contact the maintainer via GitHub
[@gu437](https://github.com/gu437).

## Scope

F12x is a local Chrome extension. It has no backend and no telemetry. Reports
about the extension UI, CDP handling, storage, import/export, AI tool
permissions, or evidence handling are in scope.

## Secrets

Never include real cookies, tokens, API keys, or customer data in a report.
Use redacted or synthetic examples.
